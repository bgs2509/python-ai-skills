## Formatting rule: no markdown tables in responses

When responding in the terminal, NEVER use markdown tables (the `| col | col |` syntax).
Instead, use one of these formats:

- **Bullet lists** for comparisons and key-value data
- **Numbered lists** for sequential items
- **"Key: value"** format for structured data
- **Indented blocks** for grouped information

This rule applies ONLY to your conversational responses in the terminal.
When writing or editing FILES (*.md, CLAUDE.md, docs, etc.), you MAY use markdown tables — they will be rendered properly in Obsidian, VS Code preview, and other markdown viewers.
